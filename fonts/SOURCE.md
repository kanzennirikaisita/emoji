# Bundled font provenance

The bundled fonts were obtained from the official `google/fonts` repository at commit:

`5fb648bb932bf1cdcd5fd71a73b79097e8666c36`

Only the container format was converted from the upstream TTF files to WOFF2 for web delivery. Each WOFF2 byte stream is split into numbered parts and reconstructed unchanged in the browser. Glyph outlines, naming tables, and font family names were not intentionally changed.
